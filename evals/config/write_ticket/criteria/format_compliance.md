## Format Compliance

The ticket must follow the required section structure and formatting conventions.

1. The ticket contains a Story section with "As a {persona}, I need {what} so that {why}"
2. The ticket contains an Objective section stating what the ticket proves or establishes in 1-2 sentences
3. The ticket contains a Context section with background, dependencies, or references
4. The ticket contains a Tasks section with specific work items as a list
5. The ticket contains a Verification section with numbered steps to confirm completion
6. The ticket contains an Out of Scope section listing excluded work
7. Task lists use plain "- " markers, never checkboxes like "- [ ]"
